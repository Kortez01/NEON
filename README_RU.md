# NEON REVENANT — нативная демоверсия для Windows 11

Это отдельная настольная версия проекта на Godot Engine 4.6. Игра запускается как обычное Windows-приложение (`.exe`); HTML, JavaScript, браузер и веб-сервер не используются.

## Сборка Windows EXE

1. Установи стандартную версию Godot Engine **4.6** для Windows (не .NET-версию не обязательно, проект написан на GDScript).
2. Один раз установи export templates именно для той же версии Godot: в редакторе выбери **Editor → Manage Export Templates → Download and Install**.
3. Распакуй этот проект в обычную папку, например `C:\Games\NEON_REVENANT`.
4. Запусти `build_windows.bat`. Если Godot не находится автоматически, задай полный путь перед запуском:
   ```bat
   set GODOT_PATH=C:\Tools\Godot_v4.6-stable_win64_console.exe
   build_windows.bat
   ```
5. Сборка появится в `build\NEON_REVENANT.exe` и запустится автоматически.

Можно также открыть `project.godot` в Godot и нажать F6/F5 для запуска из редактора.


## Сборка через GitHub Actions (без установки Godot на твоём ПК)

В архив добавлен workflow `.github/workflows/build-windows.yml`. Он автоматически скачивает Godot 4.6 и Windows export templates, проверяет проект, собирает нативный `NEON_REVENANT.exe` и публикует его как артефакт GitHub Actions.

1. Создай новый репозиторий на GitHub.
2. Распакуй этот архив и загрузи **содержимое папки `neon_revenant_windows_native`** в корень репозитория. Важно загрузить скрытую папку `.github/workflows` и файл `project.godot`; сам ZIP как один файл не подойдёт. Проще всего сделать это через GitHub Desktop или `git`.
3. Отправь файлы в ветку `main` или `master`. Сборка также запускается вручную: вкладка **Actions → Build Windows EXE → Run workflow**.
4. Когда задача завершится зелёным статусом, открой её страницу и скачай артефакт **NEON-REVENANT-Windows-x64** внизу страницы. Внутри будет `NEON_REVENANT.exe`.

Workflow использует официальный архив Godot 4.6 и соответствующие ему export templates. Если GitHub Actions не сможет скачать официальные файлы или если в проекте обнаружится ошибка, задача пометится как failed; в логах будет причина. Первый запуск и экспорт на настоящей Windows-машине этим способом отдельно не гарантируются — артефакт следует проверить после скачивания.

## Управление

- **W A S D** — перемещение.
- **C** — спринт.
- **Мышь** — вращение камеры и прицеливание.
- **ЛКМ** — неоновый выстрел.
- **Shift** — энергетический рывок.
- **Space** — прыжок.
- **Q** или **ПКМ** — энергетический импульс по ближайшим дронам.
- **Esc** — отпустить/захватить мышь.
- **R** — восстановить здоровье и энергию, если герой побеждён.

## Что внутри

- 3D-сцена с процедурным ночным городом, окнами, дорожными полосами, уличными фонарями, дождём, туманом, постобработкой и свечением.
- Управление персонажем от третьего лица, прыжок, спринт/рывок и столкновения с землёй и зданиями.
- Боевые дроны, снаряды, здоровье, энергия, импульс и HUD.
- Windows Desktop export preset и пакетный сценарий сборки.

## Важно о готовом EXE

В приложенный архив не включён скомпилированный `.exe`: среда, в которой подготовлены файлы, работает под Linux и не содержит Godot или Windows-экспортных шаблонов. Исходный проект и Windows Desktop preset включены; `build_windows.bat` выполняет экспорт и запускает результат на Windows 11.

## Примечания

Это игровой прототип, а не финальная AAA-игра. Город и персонажи создаются процедурно из 3D-примитивов, поэтому здесь ещё нет фотограмметрических ассетов, захвата движений или продвинутых разрушаемых объектов. Для высокой производительности предпочтительна видеокарта, совместимая с Vulkan/DirectX 12 уровня, но точная скорость зависит от компьютера. Если на устройстве нет поддержки Vulkan, можно переключить `renderer/rendering_method` в `project.godot` на `gl_compatibility` (эффекты освещения будут проще).

## Требования

- Windows 11 x64.
- Godot 4.6 + export templates для сборки из исходников.
- После сборки пользователю для запуска игры Godot отдельно устанавливать не нужно — движок упакован в экспортированный EXE.
